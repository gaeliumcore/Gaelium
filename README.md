> European KAWPOW proof-of-work cryptocurrency — GPU mining for everyone.

## Overview

Gaelium (GAEL) is a decentralized cryptocurrency based on the KAWPOW algorithm,
forked from Ravencoin. Designed to be ASIC-resistant, Gaelium allows anyone with
a standard GPU to participate in the network and earn rewards fairly.

Developed and operated by a registered European company, ensuring transparency
and long-term accountability.

## Network Parameters

| Parameter | Value |

| P2P Port | 18100 |

Connect your miner to our official pool:
```

```

Supported miners: TeamRedMiner, GMiner, T-Rex, NBMiner
